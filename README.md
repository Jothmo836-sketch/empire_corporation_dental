# Empire Corporation Dental

A modern dental clinic website for Empire Corporation Dental in Miami, Florida.

## Local development

Prerequisites: Node.js 18+

1. Install dependencies:
   `npm install`
2. Start the app:
   `npm run dev`
3. Build for production:
   `npm run build`

## Deployment

This is a static Vite app and can be hosted on any static hosting platform such as Netlify, Vercel, GitHub Pages, Cloudflare Pages, or any web server that serves the generated dist folder.

To deploy:
1. Run `npm run build`
2. Upload the contents of the `dist` folder to your hosting provider
